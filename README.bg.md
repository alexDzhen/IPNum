# ipnum

Конзолна програма, която преобразува IPv4 или IPv6 адрес в числовата му стойност.

*English: [README.md](README.md)*

```console
$ ipnum 192.168.1.1
Address  : 192.168.1.1
Version  : IPv4 (32-bit)
Decimal  : 3232235777
Hex      : 0xC0A80101
Binary   : 11000000.10101000.00000001.00000001
```

## Възможности

- IPv4 адрес към 32-битово число в десетичен, шестнадесетичен и двоичен вид.
- IPv6 адрес към 128-битово число и към четири 32-битови числа.
- Собствен парсер, написан от нулата: без `inet_pton` и без външни библиотеки.
- Ясни съобщения защо даден адрес е невалиден.
- Изход, удобен за скриптове (`dec`, `hex`, `bin`, `words`, `json`), и кодове на изход.
- Интерактивен режим или четене на адреси от стандартния вход.
- Компилира се с една команда под Linux и Windows (GCC, Clang, MSVC, MinGW).

## Бърз старт

Нужни са CMake 3.20 или по-нов и компилатор за C++17.

**Linux**

```sh
git clone https://github.com/alexDzhen/ipnum.git
cd ipnum
./scripts/build.sh
./build/ipnum 192.168.1.1
```

**Windows**

Инсталирайте Visual Studio 2022 с компонента "Desktop development with C++" и
изпълнете командите в "Developer PowerShell for VS 2022", където `cmake` е наличен.

```powershell
git clone https://github.com/alexDzhen/ipnum.git
cd ipnum
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
.\build\Release\ipnum.exe 192.168.1.1
```

Двата скрипта изпълняват едни и същи три команди:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

## Употреба

```text
ipnum [опции] [адрес...]

  -f, --format <име>   text (по подразбиране), dec, hex, bin, words или json
  -h, --help           Показва помощ
  -V, --version        Показва версията
```

```console
$ ipnum --format dec 10.0.0.1 8.8.8.8
167772161
134744072

$ ipnum 2001:db8::ff00:42:8329
Address  : 2001:db8::ff00:42:8329
Version  : IPv6 (128-bit)
Expanded : 2001:0db8:0000:0000:0000:ff00:0042:8329
Decimal  : 42540766411282592856904265327123268393
Hex      : 0x20010DB8000000000000FF0000428329
32-bit words, most significant first:
  [0] 0x20010DB8 = 536939960
  [1] 0x00000000 = 0
  [2] 0x0000FF00 = 65280
  [3] 0x00428329 = 4358953
```

Без аргументи програмата влиза в интерактивен режим и чака адреси, по един на ред.

| Код на изход | Значение                              |
|--------------|---------------------------------------|
| 0            | Всички адреси са преобразувани        |
| 1            | Поне един адрес е невалиден           |
| 2            | Грешка в командния ред                |

## Как работи преобразуването

### IPv4

IPv4 адресът е четири байта, записани в десетичен вид. Първият байт е най-старшият:

```text
a.b.c.d  =  a·2^24 + b·2^16 + c·2^8 + d

192.168.1.1 = 192·16777216 + 168·65536 + 1·256 + 1 = 3232235777 = 0xC0A80101
```

В кода това е едно изместване и едно OR за всеки октет: `value = (value << 8) | octet`.

Парсерът е строг: приема точно четири октета от 0 до 255 и отхвърля водещи нули
(`01.2.3.4`), защото някои програми ги четат като осмични числа.

### IPv6

IPv6 адресът е дълъг 128 бита, тоест четири пъти по-широк от 32-битово число, и не
може да се запише в едно такова. Затова `ipnum` го показва по два начина:

- като едно 128-битово число в десетичен и шестнадесетичен вид;
- като четири 32-битови числа ("думи"), от най-старшата към най-младшата.

В C++17 няма 128-битов целочислен тип, затова стойността се пази в две 64-битови
половини ([`UInt128`](include/uint128.hpp)) и се отпечатва в десетичен вид чрез
деление на 10.

Парсерът поддържа всички форми от RFC 4291: пълна, съкратена с `::`, с IPv4 накрая
(`::ffff:192.168.1.1`) и със зона (`fe80::1%eth0`, зоната се игнорира). За адреси от
вида `::ffff:a.b.c.d` се показва и 32-битовата стойност на вградения IPv4 адрес.

## Тестове

Тестовете използват [doctest](https://github.com/doctest/doctest), включен в
`third_party/`, така че при компилация не се тегли нищо.

- Модулни тестове за IPv4 парсера, IPv6 парсера, 128-битовата аритметика,
  форматирането и командния ред.
- Тестове, които стартират самата програма.
- Под Linux: сравнение със системната функция `inet_pton` върху стотици хиляди
  случайни низове.

```sh
ctest --test-dir build -C Release --output-on-failure
```
